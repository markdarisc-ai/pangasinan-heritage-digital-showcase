# Activity 2 Submission Checklist

## Deliverable 2.1 – Static Site Generation
- Static export enabled with `output: 'export'`.
- Destination routes generated using `generateStaticParams()`.
- Atomic Design component folders are present.
- Mobile-first responsive CSS is included.
- GitHub Pages path support is configured with `basePath`.

## Deliverable 2.2 – GitHub Repository & Pages
- Repository must be public.
- Update `README.md` with your student name and final links.
- Push this project to the `main` branch.
- In GitHub: **Settings → Pages → Source → GitHub Actions**.
- Wait for the `Deploy Next.js to GitHub Pages` workflow to finish.
- The Pages URL should follow `https://USERNAME.github.io/REPOSITORY/`.

## Deliverable 2.3 – Lighthouse Audit
Run Lighthouse in Chrome on the live GitHub Pages URL.
Select:
1. Performance
2. Accessibility
3. Best Practices
4. SEO

Save the result as a screenshot or PDF.

Target scores from the activity:
- Performance: ≥ 80
- Accessibility: ≥ 85
- Best Practices: ≥ 85
- SEO: ≥ 90
